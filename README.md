# ЦифраФинанс — дашборд мониторинга портфеля (Streamlit)

Рабочий дашборд еженедельного мониторинга кредитного портфеля. Backend + frontend на Python
(Streamlit + Plotly). Содержит все шесть обязательных элементов и фильтры.

## Состав (это и есть деплой-репозиторий)
```
streamlit/
├── app.py                 # приложение (бэк + фронт)
├── requirements.txt       # зависимости
└── data/
    ├── loan_portfolio_scored.csv   # очищенный + размеченный датасет
    └── branch_reference.csv        # плановые KPI по «регион-канал»
```

## Элементы
1. Четыре KPI: объём портфеля, default rate (с целью 10%), Expected Loss, средний DTI.
2. Двухосевой график: выдачи (столбцы) и default rate (линия) по кварталам.
3. Тепловая карта default rate «канал × тип занятости».
4. Scatter: credit_score × DTI, цвет — дефолт / не дефолт.
5. Таблица план-факт по справочнику с подсветкой отклонений (красный — хуже плана,
   зелёный — лучше; «нет плана» — срез не покрыт справочником).
6. Фильтры: регион, канал, продукт, период (кварталы).
