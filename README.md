# ЦифраФинанс — дашборд мониторинга портфеля (Streamlit)

Рабочий дашборд еженедельного мониторинга кредитного портфеля. Backend + frontend на Python
(Streamlit + Plotly). Содержит все шесть обязательных элементов и фильтры.

## Состав (это и есть деплой-репозиторий)
```
streamlit/
├── app.py                 # приложение (бэк + фронт)
├── requirements.txt       # зависимости
└── data/
    ├── loan_portfolio_scored.csv   # очищенный + размеченный датасет
    └── branch_reference.csv        # плановые KPI по «регион-канал»
```

## Элементы
1. Четыре KPI: объём портфеля, default rate (с целью 10%), Expected Loss, средний DTI.
2. Двухосевой график: выдачи (столбцы) и default rate (линия) по кварталам.
3. Тепловая карта default rate «канал × тип занятости».
4. Scatter: credit_score × DTI, цвет — дефолт / не дефолт.
5. Таблица план-факт по справочнику с подсветкой отклонений (красный — хуже плана,
   зелёный — лучше; «нет плана» — срез не покрыт справочником).
6. Фильтры: регион, канал, продукт, период (кварталы).

## Запуск локально
```bash
pip install -r requirements.txt
streamlit run app.py
```
Откроется на http://localhost:8501

## Публикация — Streamlit Community Cloud (бесплатно, публичная ссылка)
1. Создайте **публичный** репозиторий на GitHub и загрузите в его корень содержимое папки
   `streamlit/` — то есть `app.py`, `requirements.txt` и папку `data/`.
2. Зайдите на **https://share.streamlit.io**, войдите через GitHub.
3. **Create app → Deploy a public app from GitHub**.
4. Repository — ваш репозиторий, Branch — `main`, Main file path — `app.py`. Нажмите **Deploy**.
5. Через 1–2 минуты появится публичный URL вида `https://<имя>.streamlit.app`.
6. Вставьте ссылку в отчёт и приложите скриншот (лежит в `03_дашборд/`). Скриншот и живой
   дашборд должны совпадать.

> Приложение самодостаточно: данные лежат в `data/` внутри репозитория, внешние источники не
> нужны. Пути в коде относительные — деплой работает без правок.
